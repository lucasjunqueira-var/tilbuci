TilBuci Showtime for Makers / Espressif ESP32

This is your Showtime for Makers project for the Espressif ESP32 platform. With it, you will load your TilBuci movie onto a device that broadcasts its own Wi-Fi network, which people can access to view your content.

In the compressed file you will find two folders, "card" and "sketch". The contents of the "card" folder should be copied to an SD card formatted in exFAT. The contents of the "card" folder contain both your movie and the TilBuci platform ready for playback.

The "sketch" folder contains code to be opened in the Arduino* IDE. This code is prepared to configure an ESP32-based board to create a Wi-Fi access point and serve the content of your movie to devices that connect to it. The code is currently designed for a traditional ESP32-CAM (AI-Thinker) board that already has both the ESP32 and the SD card reader built-in.

If your board is different, don't worry: the sketch code has been divided into files according to functionality, so it will be easy to adapt it to your needs (such as adjusting access to the SD card).

If your movie needs to interact with hardware beyond just transmitting content, look for the "HardwareHandler.cpp" file to add the necessary code. If you need the card to send commands to connected devices, check the "sendAction" function, also described in that file.

All the code is well commented so you can easily adapt it to your installation.
